### Nmap Basics
#### What Nmap is:  Nmap is a network scanning tool.
#### what I learned
 -Nmap can be used to discover open ports
 -Nmap can be used to identify services
 -Nmap can be used to perform version detection.
#### example
 Nmap 192.168.1.10
#### What a port is: A port is virtual point where network connection starts and ends. 
#### example
 -Port 80
 -Port 22
 -Port 21 
 -Port 443
 -Port 3389
#### What an open port means: An open port means a service is actively listening on that port and is prepared to accept network connections.
#### what I learned
-TCP is connection-oriented. It establishes a connection between devices before transmitting data and provides reliable and ordered delivery.
- UDP is connectionless. It sends data without establishing a connection first and does not guarantee delivery or ordering.
#### One Nmap command I have learned  -sV is one Nmap I have learned
#### What -sV 
- -sV tells Nmap to perform Service Version Detection.
